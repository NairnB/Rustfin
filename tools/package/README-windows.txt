Rustfin — a fast native Jellyfin client (test build)

1. Unzip this folder anywhere (for example your Desktop). Keep Rustfin.exe and libmpv-2.dll together.
2. Double-click Rustfin.exe. Windows may say "Windows protected your PC" because the app is not signed:
   click "More info", then "Run anyway". This only happens the first time.
3. Pick your Jellyfin server from the list (or type its address, e.g. 10.0.0.20:8096) and sign in
   with your Jellyfin user, or use Quick Connect.

Keys: arrows to move, Enter to choose, Esc or Backspace to go back, Space to pause.
Your settings are kept in %APPDATA%\Rustfin. Delete that folder to start fresh.

Video playback uses mpv (libmpv-2.dll), which is GPL-licensed: see LICENSES\mpv-and-ffmpeg.txt for where to get its source.
